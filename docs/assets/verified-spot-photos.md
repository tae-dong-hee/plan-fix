# 검증된 장소 대표사진

2026-09-19에 사진이 비어 있던 실제 장소 17곳을 검수했다. 관광공사 중복 콘텐츠 11곳,
Wikimedia Commons의 특정 국가유산 사진 2곳, 공공누리 제1유형 사진 4곳을 사용한다.
유료 API 호출은 없다.

## 출처와 장소 일치 확인

- [기계 판독 출처·검수 기록](./verified-spot-photo-sources.json): 원본 URL, SHA-256, 대상 ID,
  원본 콘텐츠 ID, 이름·주소·좌표, 사진 속 확인 요소 및 제외 사례.
- `frontend/src/constants/verified-spot-images.json`: 저작자·라이선스·원본 링크.
- `backend/src/main/resources/verified-spot-images.json`: 재수집 때 적용할 정확한 대상 목록.

기존 사진이 없는 곳만 대상으로 삼았다. 이름·도로명주소·좌표를 먼저 대조하고, 간판·건물·고유
구조물을 사진에서 확인했다. 전화와 인허가번호는 보조 근거로 사용했으며 단독 매칭 조건으로
사용하지 않았다. 같은 건물의 다른 업체, 비슷한 명칭의 해변·역, 다른 지점 등은 제외했다.

도깨비젤라또의 대표는 실제 상품 사진이다. 대표 컵만으로 업체를 단정하지 않고, 동일 출처의
로고 사진과 장소 메타데이터를 함께 확인했다. BTS 정류장 두 좌표는 약 146m 차이가 있으므로
근접성만으로 승인하지 않았다. 고유 촬영지 설명과 실제 정류장 표식을 함께 확인했다.

이는 출처와 장소 일치 검수이며 최근 현장 촬영을 보장하지 않는다. Commons 사진 촬영일은
임당동 성당 2018-10-01, 당간지주 2016-05-30이다. 공공누리 사진 4장은 모두 2018년 촬영이다.
확인하지 못한 장소는 기본 이미지를 유지한다.

공공누리에서 추가한 4장은 강원특별자치도와 한국문화정보원이 촬영하고 강원특별자치도가
보유한 개별 작품이다. 각각의 작품 페이지에서 제1유형을 확인했다. 공개 페이지가 직접 제공하는
760×507 미리보기 파일을 받아 편집·축소 없이 보존했으며, 로그인 후 제공하는 고해상도 원본은
아니다. 작품명·촬영연도·해상도·출처 링크를 사진 출처 화면에 함께 표시한다.

수리골 고택은 관광공사와 강원도 문화재 시행계획에서 운정길 125로 확인했지만 국가유산 연계자료
일부는 123으로 기재되어 있다. 이 차이를 검수 기록에 남겼다. 산계리 석탑(527)은 공식 지번과
DB 도로명주소의 대응을 확인하지 못해 이번 추가 대상에서 제외했다. 경포호 사진은 실제 호수
풍경이며, 철새가 등장하는 사진은 아니다.

## 적용과 보존

기존 13곳의 [보정 SQL](../migrations/2026-09-19-backfill-verified-spot-photos.sql)은 대상·원본의
ID/contentid·주소·좌표·상태와 현재 빈 사진 여부를 트랜잭션 안에서 다시 확인한다. 다른 사진이
생겼거나 장소 정보가 바뀌었으면 전체를 중단한다. 실행 전 원본 행을 백업한다. 재실행은 추가
변경 없이 끝난다. 원본 `tour_data_spots`와 `tour_data_images`는 변경하지 않는다.

공공누리 사진 4곳은 [추가 보정 SQL](../migrations/2026-09-19-backfill-kogl-spot-photos.sql)로
별도 적용한다. 동일하게 장소 정보와 빈 사진 여부를 다시 확인하고 실행 전 상태를 보존한다.

재수집은 API가 제공한 대표사진을 우선한다. API 사진이 없고 검수 당시의 ID·이름·주소·좌표가
모두 일치할 때만 이 목록의 사진을 대체 사용한다. 장소가 이전·개명됐거나 다른 지점이면 붙이지
않는다. 검수 목록에 없는 곳을 유사도나 이미지 검색으로 자동 채우지 않는다.

상세 화면의 ‘사진 출처’에서 저작자와 원본·이용 조건을 확인할 수 있다. 원본 파일은 편집하지
않고 전체 비율로 표시해 간판·워터마크가 잘리지 않게 한다. Commons 두 파일은 CC BY-SA 4.0이다.
TourAPI는 공공누리 제1·3유형 사진을 제공하므로 개별 유형을 임의로 제1유형이라고 표시하지 않는다.
[관광공사 공식 API 설명](https://www.data.go.kr/data/15101578/openapi.do)을 함께 연결한다.
공공누리에서 직접 확인한 4장은 [제1유형 이용조건](https://www.kogl.or.kr/info/licenseType1.do)에
따라 저작자·보유기관과 출처를 표시하고 원문 하이퍼링크를 제공한다. 공개 미리보기 해상도라는
점을 명시하며 고해상도 원본으로 소개하지 않는다.

## 추가 수집 제약

[포토코리아 API](https://www.data.go.kr/data/15101914/openapi.do)는 무료지만 기존 키로
최소 조회 한 번을 시도한 결과 HTTP 403 / `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`였다.
해당 API의 활용신청·승인 상태를 확인해야 추가 수집할 수 있다. 키·유료 서비스 설정은 변경하지 않았다.

공공누리는 개별 작품의 명칭·기관·촬영연도·라이선스·공개 사진 URL을 수집할 수 있으나, 장소 ID가
공통으로 제공되지 않아 주소와 사진 내용을 별도로 대조해야 한다. 고해상도 다운로드에는 로그인이
필요하다. 강릉시 관광 페이지 전체를 재사용 가능하다고 간주하지 않는다. 제4유형으로 공개된
페이지와 사진은 이번 목록에 포함하지 않았다.
