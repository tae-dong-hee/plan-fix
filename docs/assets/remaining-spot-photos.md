# 누락 장소 사진 후속 검수

Google 카드가 연결되지 않은 492곳을 재검토했다. 기존 사진 보유 장소와 공공시설 갤러리를 교차 대조해 강릉통일공원안보전시관(534)의 실제 건물 사진 1장을 추가했다. 원본은 관광공사 통일공원(강릉, 420)의 갤러리이며 대표 기념비 사진과 구분해 건물 사진만 선택했다. 두 레코드의 도로명·건물번호·전화번호가 같고 좌표는 약 6.6m 차이다. 사진 외벽의 통일안보전시관 표기도 확인했다.

[개별 검수 기록](remaining-spot-photo-review-2026-09-19.json)에 원본·SHA256·사용조건과 검증 한계를 기록했다. 원본 사진을 편집하지 않고 전체 비율과 한국관광공사 워터마크를 유지한다. 촬영일과 현재 현장 상태는 확인하지 않았다.

프런트의 사진 출처 표시와 백엔드의 정확한 장소 신원 기반 재수집 보존 목록에 추가했다. 별도 SQL은 운영 대상·원본의 ID·이름·주소·좌표·기존 사진 상태를 다시 확인한 뒤 대상의 빈 대표사진만 채운다. 기존 원본 갤러리와 장소 신원은 바꾸지 않는다. 적용 뒤 목록과 상세에 같은 실제 사진이 표시된다. 기존 Google 카드63곳은 유지된다.

이 작업으로 남은 미연결 장소는491곳이며, 전체 사진 누락 해결을 뜻하지 않는다. 공식 호텔 사이트의 사진은 발견만으로 재사용 승인을 하지 않았다. 위치 지도 대체안은 별도 선택 사항으로 운영에 추가하지 않았다.
