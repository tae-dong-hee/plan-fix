# 인기 장소 유사 이미지

메인의 인기 장소·지역 추천 카드, 인기 장소(`/spots/popular`)·여행 장소(`/spots`) 목록, 장소 상세 대표 사진, 위시리스트, 장소 검색, 코스 작성·상세의 장소 썸네일에서 사진이 없거나 로딩이 실패하면 장소 종류에 맞는 사진을 표시한다. 기존 원본 사진이 정상 로드되면 그대로 사용한다. DB의 `thumbnail`과 실제 상세 갤러리 목록은 변경하지 않는다. 승인된 Google 장소 사진 카드도 기존 우선순위를 유지한다.

## 사진 선택

- `frontend/src/lib/similar-spot-images.ts`: 음식점·카페·숙소·관광지 등 분류 안에서 구체적인 이름 키워드를 우선 적용한다. 닭갈비와 갈비, 짬뽕순두부와 일반 순두부, 해변과 바닷가모텔 등을 구분한다.
- `frontend/src/constants/similar-spot-menu-hints.json`: 이름만으로 음식 종류를 판단하기 어려운 기존 식당 261곳의 대표 메뉴. 2026-09-20 공개 `/api/v1/spots/{spotId}`의 `info.firstMenu`를 확인했다. ID·상호·분류가 모두 같은 경우에만 참고한다. 새 장소나 상호 변경 시 일반 분류 규칙을 사용하며, 추가 API를 호출하지 않는다. 메뉴 변경 시 이 참고 자료도 갱신해야 한다.
- 같은 유형 안에서 지역이 같은 사진을 우선하고, 동일한 장소에는 항상 같은 사진을 배정한다.
- `frontend/src/constants/similar-spot-images.json`: 검수한 사진 68장의 원본 출처·저작자·이용 조건·지역·유형을 보관한다. 실제 다른 장소의 간판을 대표 이미지로 사용하지 않도록 음식·객실·풍경·실내 위주로 골랐다.

이미지에 **유사 이미지** 표시와 접근성 설명을 붙이고, 목록 하단과 상세에서 사진 출처로 이동할 수 있다. 48~56px 크기의 작은 썸네일에는 **유사**로 줄여 표시하되 대체 텍스트와 출처 설명은 유지한다. 대표 메뉴가 없거나 이름의 단서가 부족하면 해당 분류의 일반적인 사진을 사용한다. 실제 메뉴·객실·시설을 보장하는 사진으로 취급하지 않는다.

## 원본과 저장

기존 서비스가 사용하는 한국관광공사 TourAPI 장소 사진 40장과 기존 코스 이미지 카탈로그의 사진 28장을 재사용했다. TourAPI 원본 이미지 URL과 원래 장소명/ID를, 코스 이미지는 기존 저작자·라이선스·원본 출처를 유지한다. 다른 라이선스로 재지정하지 않는다. 사진 출처 페이지에서 각 항목을 확인할 수 있다.

`frontend/public/images/spot-fallbacks/`에 최대 800px WebP로 포함한다. 원본 비율을 유지해 축소했으며 원본 워터마크를 삭제하지 않았다. 카드에서만 `object-cover`로 표시한다. 외부 이미지 호스트나 사진 검색 API가 일시적으로 실패해도 대체 이미지를 읽을 수 있다. 대체 파일까지 읽지 못하면 기존 SVG로 종료하며 재요청 루프를 만들지 않는다.

## 확인 결과

2026-09-20 공개 목록 4,760곳 중 `thumbnail`이 비어 있는 1,083곳에 모두 유사 이미지가 연결되었다. 정상 원본 사진 유지, 로딩 오류 시 단계별 복구, 분류/지역 매칭, 대표 메뉴의 상호 변경 방어, 출처 연결 및 모든 이미지 파일의 브라우저 디코딩을 확인했다. 이 수치는 확인 시점의 스냅샷이며 이후 수집 데이터에 따라 달라진다.
