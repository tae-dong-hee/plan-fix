# 코스 기본 대표 사진

대표 이미지가 없는 공개 코스에 사용할 강원도 사진 20장을 S3에 저장했습니다. 메인 화면과 공개 코스 목록에서 사용합니다.

- S3 경로: `defaults/course-covers/2026-09-v1/`
- 파일: Wikimedia Commons에서 제공한 1280px JPEG 축소본, 총 약 7.8MB
- 원본·저작자·라이선스·체크섬: [course-cover-sources.json](./course-cover-sources.json)
- 실행용 카탈로그: `backend/src/main/resources/course-cover-images.json`, `frontend/src/constants/course-cover-images.json`
- 화면 출처: `/image-credits`와 각 카드의 `사진 출처` 링크

## 사진 선택

사용자가 지정한 `thumbnail`을 우선합니다. 대표 이미지가 없으면 코스에 실제로 포함된 장소의 강원 법정동 시군구 코드로 후보를 고르고, 코스 제목·설명과 장소 정보에서 사진에 맞는 구체적인 장소명·테마를 찾습니다. 같은 우선순위의 후보 중에서 코스 ID를 시드로 사진을 선택하므로 새로고침이나 목록 정렬 변경으로 사진이 바뀌지 않습니다.

해당 시군의 사진이 없으면 전체 카탈로그에서 관련 후보를 선택합니다. 사진은 지역·테마를 나타내는 기본 이미지이며, 코스의 모든 방문지를 직접 촬영한 사진이라는 의미는 아닙니다. 코스의 장소나 설명, 카탈로그를 변경하면 선택 결과가 달라질 수 있습니다.

DB의 `thumbnail`에는 기본 사진을 저장하지 않습니다. 공개 목록 응답에만 표시용 URL을 채우며, 코스를 편집해도 기존에 지정한 대표 이미지는 유지합니다.

## 비공개 S3에서 이미지 제공

연결된 S3 버킷은 공개 접근이 차단되어 있으므로 직접 URL은 403을 반환합니다. 버킷 정책을 변경하지 않고 `GET /api/v1/images/course-covers/{id}?v=2026-09-v1`을 통해 카탈로그에 등록된 사진만 제공합니다. 프론트는 카탈로그와 정확히 일치하는 기본 이미지 URL에만 이 API를 사용합니다.

백엔드는 고정된 카탈로그의 S3 키만 읽고 가져온 파일을 메모리에 캐시합니다. 임의 URL이나 S3 키를 요청할 수 없습니다. 동일 버전 파일을 덮어쓰지 않으며, 이미지를 교체할 때는 새로운 ID·버전 경로와 체크섬을 사용해야 합니다.

배포하려면 프론트와 백엔드 변경을 함께 반영해야 합니다. 기존 `VITE_API_BASE_URL`과 백엔드 S3 설정을 사용하며, 별도 프론트 AWS 키는 필요하지 않습니다.

## 출처와 파일 관리

CC0, CC BY, CC BY-SA 사진으로 구성했습니다. 개별 저작자와 라이선스 링크는 카탈로그 및 출처 화면에 기록했습니다. Commons 제공 파일을 그대로 저장하고, 화면에서는 `object-fit: cover`로 표시합니다. 파일 자체를 편집·재배포할 때는 해당 사진의 라이선스 조건을 유지해야 합니다.

두 실행용 카탈로그는 동일하게 관리합니다. 새 사진을 추가하거나 교체할 때 원본 출처와 라이선스, S3 파일 체크섬을 함께 확인해야 합니다. 기본 사진 수를 변경하는 경우 백엔드 카탈로그 검증의 20장 조건도 함께 변경해야 합니다.
