# 코스 기본 대표 사진

대표 이미지가 없는 공개 코스에 사용할 사진 40장을 S3에 저장했습니다. 기존 강원도 사진 20장에 숙소·겨울·액티비티 등 테마 사진 20장을 추가했습니다. 메인 화면과 공개 코스 목록에서 사용합니다.

- 기존 S3 경로: `defaults/course-covers/2026-09-v1/` (20장 유지)
- 추가 S3 경로: `defaults/course-covers/2026-09-v2/` (20장, 5,790,007바이트)
- 파일: Wikimedia Commons에서 제공한 1280px JPEG 축소본, 파일 편집 없이 저장
- 원본·저작자·라이선스·체크섬: [course-cover-sources.json](./course-cover-sources.json)
- 실행용 카탈로그: `backend/src/main/resources/course-cover-images.json`, `frontend/src/constants/course-cover-images.json`
- 화면 출처: `/image-credits`와 각 카드의 `사진 출처` 링크

## 사진 선택

사용자가 지정한 `thumbnail`을 우선합니다. 대표 이미지가 없는 코스는 실제 포함된 장소의 강원 법정동 시군구 코드로 지역 후보를 고르고, 코스 제목·설명과 장소 정보에 맞는 범용 테마 사진도 후보로 사용합니다. 구체적인 장소명·키워드·테마 점수가 높은 사진을 먼저 고려하되, 최고 점수 한 장으로 후보를 제한하지 않습니다.

공개 목록에 포함된 코스들의 사진을 함께 배분하여 **관련 후보 안에서 고유 이미지 수를 최대화**합니다. 먼저 후보가 적은 코스부터 배분하며, 충돌하면 기존 배정을 다른 후보로 옮겨 불필요한 중복을 줄입니다. 직접 지정한 사진은 그대로 유지하고 자동 배분 전에 사용 중인 것으로 계산합니다. 관련 후보가 부족한 경우에만 재사용하며, 사용 횟수가 적은 사진을 우선합니다.

같은 코스 집합은 코스 ID와 고정 시드를 사용하므로 새로고침·목록 순서·카탈로그 순서가 바뀌어도 배분이 같습니다. **페이지 크기나 포함된 코스 집합이 바뀌면 사진 배분은 달라질 수 있습니다.** DB의 기존 대표사진을 수정하거나 별도 배분 상태를 저장하지 않습니다.

해당 시군의 사진이 없으면 전체 카탈로그에서 관련 후보를 선택합니다. 관련 단서까지 없을 때는 전체 카탈로그를 기본 후보로 사용합니다. 지역 후보가 있으면 중복 회피만을 위해 다른 지역 사진이나 내용과 무관한 범용 사진을 끌어오지 않습니다. 사진은 지역·테마를 나타내는 기본 이미지이며, 코스의 모든 방문지를 직접 촬영한 사진이라는 의미는 아닙니다. 해외 촬영을 포함한 범용 사진에는 강원 시군구 코드를 붙이지 않으며, 제목과 출처 안내에서 테마 사진임을 밝힙니다.

2026-09-13 추가 구성은 숙소·캠핑 4장, 겨울 풍경 3장, 바다 2장, 액티비티 5장, 카페·디저트 3장, 음식 2장, 문화 1장입니다. 숙소와 겨울 테마 사전, 카누·카약 키워드를 추가했습니다. 추가 사진의 원본·검수 내역은 [추가 검수 기록](./course-cover-expansion-2026-09-13.md)을 참고하세요.

DB의 `thumbnail`에는 기본 사진을 저장하지 않습니다. 공개 목록 응답에만 표시용 URL을 채우며, 코스를 편집해도 기존에 지정한 대표 이미지는 유지합니다.

## 비공개 S3에서 이미지 제공

연결된 S3 버킷은 공개 접근이 차단되어 있으므로 직접 URL은 403을 반환합니다. 버킷 정책을 변경하지 않고 `GET /api/v1/images/course-covers/{id}?v={version}`을 통해 카탈로그에 등록된 사진만 제공합니다. 프론트는 카탈로그와 정확히 일치하는 기본 이미지 URL에만 이 API를 사용하며, S3 키에서 각 사진의 `2026-09-v1` 또는 `2026-09-v2` 버전을 읽습니다.

백엔드는 고정된 카탈로그의 S3 키만 읽고 가져온 파일을 메모리에 캐시합니다. 최대 40장, 파일당 최대 5MB로 제한합니다. 임의 URL이나 S3 키를 요청할 수 없습니다. 동일 버전 파일을 덮어쓰지 않으며, 이미지를 교체할 때는 새로운 ID·버전 경로와 체크섬을 사용해야 합니다.

배포하려면 프론트와 백엔드 변경을 함께 반영해야 합니다. 기존 `VITE_API_BASE_URL`과 백엔드 S3 설정을 사용하며, 별도 프론트 AWS 키는 필요하지 않습니다.

## 출처와 파일 관리

CC0, CC BY, CC BY-SA, 저작자의 퍼블릭 도메인 기증, 공공누리 제1유형 사진으로 구성했습니다. 개별 저작자와 라이선스 링크는 카탈로그 및 출처 화면에 기록했습니다. Commons 제공 파일을 그대로 저장하고, 화면에서는 `object-fit: cover`로 표시합니다. 파일 자체를 편집·재배포할 때는 해당 사진의 라이선스 조건을 유지해야 합니다.

두 실행용 카탈로그는 동일하게 관리합니다. 새 사진을 추가하거나 교체할 때 원본 출처와 라이선스, S3 파일 체크섬을 함께 확인해야 합니다. 40장을 초과하는 경우 선택기와 이미지 제공 서비스의 카탈로그 상한 및 캐시 용량을 함께 검토해야 합니다.
