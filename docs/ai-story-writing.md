# 사진으로 여행 이야기 작성

`/boards/create`에서 **AI로 작성 / 직접 작성**을 선택합니다. AI 작성에서 여행 사진을 고르면 사진 내용을 분석해 본문을 자동으로 채웁니다. 선택 메모로 장소나 함께 담고 싶은 기억을 전달할 수 있습니다. 제목은 사용자가 직접 작성합니다.

- JPG·PNG·WebP 1~6장, 장당 5 MiB, 전체 15 MiB까지 지원합니다.
- 생성한 본문은 기존 에디터에서 수정할 수 있습니다. 기존 글이 있거나 생성 중 제목/본문을 수정하면 새 초안을 별도로 보여주고, 뒤에 추가하거나 본문을 교체할 수 있습니다.
- 직접 작성으로 전환해도 본문과 선택 사진을 유지합니다. 생성 중 직접 작성으로 전환하면 늦게 도착한 결과를 적용하지 않습니다.
- 사진은 발행 시 기존 이미지 업로드 API로 저장되고 게시글 사진 목록에 포함됩니다. 별도 커버가 없으면 첫 번째 선택 사진을 커버로 사용합니다. 발행 실패 후 재시도할 때 이미 업로드한 사진 URL을 재사용합니다.

## API와 설정

인증된 `POST /api/v1/boards/ai-draft` 요청에 multipart `files`를 반복해 전달하고, 선택적으로 `title`(100자 이하), `note`(500자 이하)를 보냅니다. 응답은 `{ "content": "일반 텍스트 본문" }`입니다. 이 API는 게시글이나 사진을 저장하지 않습니다.

기존 `GEMINI_API_KEY`, `GEMINI_MODEL`을 사용합니다. 사진 작성 전용 모델은 재시도 없이 60초로 제한하며, 브라우저는 90초 후 재시도 안내를 표시합니다. API가 준비되지 않았거나 생성에 실패하면 오류를 반환하며 임의의 여행담으로 대체하지 않습니다. 본문은 HTML 문자열 대신 에디터의 텍스트 노드로 삽입합니다.

서버는 파일 서명·실제 이미지 디코딩·해상도·용량을 검사하고, 사진을 최대 1280px JPEG로 변환하여 Gemini에 전달합니다. 원본 사진과 메모, 모델 요청/응답은 로그에 기록하지 않습니다. 서버 인스턴스마다 사용자별 동시 요청 1개, 시간당 10회, 전체 동시 요청 4개로 제한합니다.

## 확인

```sh
cd frontend
npm run typecheck
npm test
npm run build
```

Java 21에서 백엔드의 `BoardAiDraftApplicationServiceTest`, `StoryImagePreparerTest`, `StoryDraftRateLimiterTest`, `BoardAiDraftControllerTest`로 멀티모달 요청, 잘못된 이미지, 실패 응답, 호출 제한, 인증을 검증합니다. 테스트는 실제 Gemini와 운영 DB를 호출하지 않습니다.
