# 코스 공개 범위

`PRIVATE`는 작성자만 접근하는 **나만 보기**, `PUBLIC`은 누구나 조회하는 **전체 공개**입니다. 초대 멤버는 공개 코스에만 참여할 수 있고, 공개 범위 변경은 작성자만 할 수 있습니다.

| 동작 | 나만 보기 | 전체 공개 |
| --- | --- | --- |
| 상세·일정·메모 조회 | 작성자만 | 누구나 |
| 내 코스 목록 | 작성자만 | 작성자와 참여 멤버 |
| 공개 목록 | 제외 | 포함 |
| 좋아요·위시리스트 | 작성자만 | 로그인 사용자 |
| 친구 초대·초대 미리보기·수락 | 불가 | 가능 |
| 여행 이야기의 코스 연결 | 불가 | 작성자만 연결 가능 |
| 코스 내용 수정 | 작성자만 | 작성자와 EDITOR |
| 공개 범위 변경 | 작성자만 | 작성자만 |

작성자가 나만 보기로 저장하면 한 트랜잭션 안에서 멤버와 초대 링크를 삭제하고, 다른 사용자의 좋아요를 삭제한 뒤 좋아요 수를 다시 계산합니다. 작성자의 좋아요는 유지합니다. 기존 여행 이야기에서는 코스 연결만 해제하고, 별도로 발행한 이야기 본문은 유지합니다. 이후 다시 전체 공개로 변경해도 해제된 초대·권한·좋아요·이야기 연결은 자동 복원하지 않습니다.

기존 비공개 데이터에 멤버·좋아요·초대가 남아 있어도 각 조회·수정 경로에서 접근을 차단합니다. 해당 코스를 저장하거나 다시 공개할 때 남아 있는 공유 데이터도 정리하므로 과거 권한이 되살아나지 않습니다. 별도 스키마 변경은 필요하지 않습니다.

여행 이야기를 생성하거나 수정할 때 비공개 코스를 연결하면 HTTP 400과 공개 전환 안내를 반환합니다. 코스를 자동으로 공개로 바꾸지 않습니다. 비공개 초대 링크의 미리보기·수락은 코스 제목 없이 일반 HTTP 404로 응답합니다. 권한 없는 상세·좋아요·수정·숙소 조회는 HTTP 403으로 응답합니다.

비공개 전환, 초대 생성·수락·취소, 멤버 권한 변경·삭제, 좋아요 및 이야기 연결은 같은 코스 행의 비관적 쓰기 잠금을 사용합니다. 초대 수락은 잠금을 얻은 뒤 토큰을 다시 확인하므로 전환 중 폐기된 링크로 멤버십을 복구할 수 없습니다.

## 검증

실행에는 Java 21과 Docker가 필요합니다. Spring 테스트는 기존 Testcontainers 설정의 임시 PostgreSQL을 사용하며 운영 DB로 연결하지 않습니다.

```sh
cd backend
./gradlew test

cd ../frontend
npm test
npm run typecheck
npm run build
```

주요 회귀 테스트:

- `CoursePrivacyIntegrationTest`: 실제 쿠키 인증과 DB로 사용자별 조회, 기존 데이터 우회, 좋아요 제거, 초대 해제, 자동 공개 금지, 실패 시 원자성을 검증합니다.
- `CoursePrivacyConcurrencyTest`: PostgreSQL의 실제 잠금 대기를 관찰하며 초대 수락과 비공개 전환이 겹쳐도 권한이 남지 않는지 검증합니다.
- `CourseInviteApplicationServiceTest`: 비공개 초대 차단, 공개 초대 유지, 잠금 대기 중 폐기된 토큰 재사용 차단을 검증합니다.
- 생성·수정·상세·여행 후기 화면과 서비스 테스트: 비공개 초대 숨김, 비공개 이야기 연결 차단, 공개 전환 안내와 API 오류 전달을 검증합니다.
